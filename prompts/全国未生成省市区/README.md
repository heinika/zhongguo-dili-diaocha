## 使用说明

1. 每次复制一个完整代码块进行生图，不要批量塞入同一轮生成。
2. 生图前用最新官方行政区地图复核边界、主要水系、山脉、海岸和地标方位。
3. 输出最高可用分辨率的原始 PNG，并按省份目录归档。
4. 若中文小字不清，可只做文字修正版，不改动地理骨架和构图。
