# 样板图转手绘地图流程

本文记录“样板图 → 复古手绘地图”的流程，适用于嫩江、黑河这类已经有样板图、真实轮廓、图标和橙色标签的城市主图。

## 核心原则

- 样板图是空间骨架，手绘图只是风格化表达，不能重新构图。
- 先解析样板图，再写提示词；不要只凭肉眼概括“像参考图”。
- 橙色标签通常是用户指定需要保留的信息，必须全部保留。
- 行政区划底色、乡镇/村屯小字、密集道路网、铁路、高速方向提示、外部方向箭头等，除非用户明确要求，否则不要作为手绘图信息主体。
- 如果用户要求“位置对齐”“像素级一致”，不要继续依赖纯图像生成模型自由绘制；应采用“硬轮廓 / 坐标锚点 / 后期贴标”的思路。

## 标准步骤

1. 读取样板图，确认画布尺寸、标题区位置、地图主体位置、外轮廓形态、水系和橙色标签。
2. 用 `tools/extract_orange_label_anchors.py` 解析橙色标签的像素框和中心点，输出编号表。
3. 人工查看编号裁切表，把每个编号对应到准确中文标签名；剔除误检的橙色道路、箭头和外部方向提示。
4. 把外轮廓写成提示词：描述整体 bounding box、北端、东侧凸出、西侧江岸、中部宽窄、底部形状、重要凹口和水系出口。
5. 保存 `{城市拼音}_coordinate_prompt.txt`，并把样板图、坐标表、生成图放到对应城市目录。
6. 第一次可用完整坐标提示词生成手绘图；检查轮廓是否跑偏、标签是否缺失、是否出现铁路/高速方向/行政底图信息。
7. 如果轮廓仍跑偏，改用硬蒙版流程：用样板图提取真实外轮廓作为裁切蒙版，生成无文字手绘底图，再按解析坐标贴回橙色标签。
8. 若中文标签生成不稳定，最终发布前应手动覆盖关键文字，或者从样板图裁出橙色标签按坐标贴回。

## 工具用法

```bash
python tools/extract_orange_label_anchors.py \
  cities/黑龙江/黑河/heihe_sample_map.png \
  --out-dir cities/黑龙江/黑河 \
  --sheet-name heihe_label_coordinate_sheet.png \
  --cols 2
```

输出包括：

- 控制台坐标清单：`bbox=(x1,y1,x2,y2)`、`center=(x,y)`、百分比坐标和尺寸。
- 裁切编号图：用于人工把编号和中文标签对应起来。

注意：工具只做颜色与连通域解析，不做 OCR。橙色道路、外部方向箭头可能误检，必须人工排除。

## Prompt 结构

```text
Use case: style-transfer + coordinate-locked illustrated map poster
Asset type: hand-drawn vintage travel-map poster
Primary request: Generate a hand-drawn vintage {城市} poster based on the supplied sample map. The sample map is the authoritative spatial skeleton.

Authoritative canvas and layout:
- Reference canvas is {宽} x {高} px, portrait.
- Preserve the sample layout: {标题位置}; map silhouette occupies {地图位置和范围}.
- The external outline, river/water system, and orange labels must follow the sample coordinate system. Do not recenter, simplify into a generic island, or reshape the map for decorative balance.

External outline geometry:
- Overall bounding box: x≈{x1}-{x2}, y≈{y1}-{y2}.
- North/top: {北端形态}.
- West side / river side: {西侧水系或边界}.
- Middle section: {中段宽窄、凸出、凹口}.
- East side: {东侧凸出、阶梯或边界}.
- South/bottom: {底部形状，是否宽底、尖底、斜切、缺口}.

Coordinate-locked orange labels:
- {标签A}: center ({x},{y}), {相对位置说明}.
- {标签B}: center ({x},{y}), {相对位置说明}.

Style:
- Antique parchment background, thin Chinese decorative border, large brush title “{城市}”.
- Hand-drawn vintage atlas illustration, ink linework, watercolor washes, sepia outlines, muted natural colors.
- Keep the map clean: no administrative subdivision labels, no township/village base-map names, no dense grid, no railway or highway direction labels unless explicitly required.

Output: polished 9:16 PNG poster with coordinate-locked outline and labels.
```

## 嫩江避坑

嫩江样板图的北部有明显蓝色水系和湿地分叉。生成时不能把这些蓝色分叉当作行政外轮廓的“高高鹿角”。正确处理方式：

- 区分外轮廓和水系：蓝色分叉是水系/湿地结构，不是必须抬高成立体边界的角。
- 外轮廓应以绿色行政主体为主，水系作为贴边或内部/边缘水体绘制。
- 中部和底部不能画成长条尖底岛。参考样板中段是向左展开的大块城市腹地，底部是宽阔横向边界并带阶梯缺口。
- 如果提示词生成仍把嫩江画成“鹿角”或尖底岛，应停止继续纯提示词迭代，改用硬轮廓蒙版和坐标贴标。
