## 逐图空间硬约束与核验

### 00 澳门特别行政区总览

1. 北向向上；澳门半岛位于最北并与珠海陆地连续相接。
2. 氹仔位于半岛以南，路环位于最南。
3. 路氹城位于氹仔和路环之间并把二者连成连续陆地。
4. 西湾、南湾位于澳门半岛南部及西南部。
5. 友谊大桥、西湾大桥、澳氹大桥分别连接半岛与氹仔，不错接路环。
6. 大三巴、妈阁庙、议事亭前地在半岛；龙环葡韵在氹仔；路环村在路环西南。

核验：初稿因半岛北端近似孤岛被淘汰；成品已修正珠澳陆界与三桥落点，合格。

### 01 花地玛堂区

1. 位于澳门半岛最北部，关闸在北端陆界。
2. 青洲在西北，筷子基在其南侧西岸。
3. 台山、祐汉位于北部及中部密集城区。
4. 黑沙环位于东部及东北部填海岸。
5. 澳门水塘在东南侧，不能移到西岸。
6. 望厦山位于南中部；南侧继续连接半岛其他堂区。

核验：珠澳陆界、东西海岸、水塘与望厦山方向均符合约束，合格。

### 02 圣安多尼堂区

1. 位于澳门半岛西部中段，内港始终在西侧。
2. 沙梨头在西北，新桥在北至东北的街区。
3. 白鸽巢公园、东方基金会会址、基督教坟场彼此邻近。
4. 圣安多尼教堂在白鸽巢公园东南的老街网。
5. 大三巴位于南部老城，大炮台在其东侧高地。
6. 北、东、南均与半岛城区连续，不画成岛屿。

核验：内港朝向、白鸽巢片区及大三巴—大炮台关系正确，合格。

### 03 嘉模堂区

1. 以氹仔为主体，北部隔海面对澳门半岛。
2. 三座跨海大桥分别落在氹仔北岸，不直达路环。
3. 小潭山在西，大潭山在东中部。
4. 官也街、嘉模圣母堂、龙环葡韵集中于西南老氹仔。
5. 澳门国际机场沿东岸展开，氹仔码头在东北岸。
6. 南缘接入路氹城，不能画成完整封闭海岸。

核验：桥梁北岸落点、机场东岸、双山及老氹仔街区关系正确，合格。

### 04 风顺堂区

1. 位于澳门半岛西南及南部。
2. 内港在西；西湾、南湾在南及东南。
3. 妈阁庙位于最西南临水端，海事博物馆与其相邻。
4. 港务局大楼位于妈阁东北上坡处。
5. 亚婆井前地、郑家大屋位于妈阁东北内陆并互相邻近。
6. 西望洋山、主教山小堂位于南部高地，面向西湾。

核验：妈阁临水、亚婆井—郑家大屋组合与主教山朝向正确，合格。

### 05 大堂区

1. 位于澳门半岛中部、东部和东南部。
2. 外港在东岸，南湾在南侧。
3. 议事亭前地与民政总署大楼位于西中部旧城核心。
4. 主教座堂在议事亭前地东北；玫瑰堂、卢家大屋仍在旧街区。
5. 新葡京位于旧城东南、南湾附近。
6. 新口岸在东南填海区，观音像临东南海岸，外港码头在东北岸。

核验：旧城与新口岸未互换，外港、南湾及观音像方位正确，合格。

### 06 圣方济各堂区

1. 以路环为主体，位于澳门最南。
2. 北缘接入路氹城，不在北面另画海峡。
3. 路环村在西南岸，荔枝碗船厂片区紧邻其北。
4. 石排湾在北部谷地，大熊猫馆位于该片区。
5. 叠石塘山位于中南部，妈祖文化村在山上。
6. 黑沙海滩在东南岸，竹湾海滩在南至西南岸，九澳在东北岸。

核验：路环村、黑沙与竹湾未互换，北部接地及山海关系正确，合格。

### 07 望德堂区

1. 位于澳门半岛中东部，为紧凑内陆堂区，不画成海岛。
2. 东望洋山占据东部及东南部高地。
3. 东望洋炮台与灯塔位于山顶。
4. 二龙喉公园位于山北麓，松山缆车连接公园与山体。
5. 塔石广场位于山西南，卢廉若公园在其北侧。
6. 望德圣母堂与疯堂斜巷位于山西侧旧街区。

核验：全图无臆造海岸，松山、塔石、卢廉若及疯堂片区相对关系正确，合格。

### 08 路氹城

1. 位于氹仔以南、路环以北，为连续填海陆地。
2. 北、南两端均陆路相接，不画成孤岛。
3. 西侧面向横琴水道，莲花大桥向西连接横琴。
4. 澳门银河靠近北部，澳门威尼斯人位于北中部。
5. 永利皇宫、新濠天地位于东部；巴黎人、新濠影汇位于中南及西南。
6. 澳门东亚运动会体育馆在东南，路氹生态保护区在西南湿地边缘。

核验：氹仔—路氹—路环连续，主要节点东西关系和莲花大桥连接正确，合格。
