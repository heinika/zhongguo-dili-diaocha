# 江苏：江河湖海，水韵人文

江苏很适合画成一张立体手绘地图。

它不是只有江南园林，也不是只有沿海港口。长江横贯东西，京杭大运河纵穿南北，太湖、洪泽湖、骆马湖把水面铺开，黄海海岸又把湿地、盐田、港口和滩涂推向更辽阔的东方。

这组图想画的，就是江苏最鲜明的那种气质：江河成脉，湖海成境，城市在水网里生长。

## 这组图里画了什么

江苏省总图：长江、京杭大运河、太湖、洪泽湖、黄海海岸、江淮平原、水乡古镇与港口城市群。

南京：紫金山、玄武湖、秦淮河、明城墙、中山陵与长江大桥。  
引用刘禹锡：“朱雀桥边野草花，乌衣巷口夕阳斜。”

无锡：太湖、蠡湖、鼋头渚、灵山大佛、惠山古镇与京杭大运河。  
引用苏轼：“水光潋滟晴方好，山色空蒙雨亦奇。”

徐州：云龙湖、云龙山、汉文化景区、汉兵马俑、龟山汉墓与戏马台。  
引用李白：“楚汉兴亡几战场，英雄成败总茫茫。”

常州：京杭大运河、天宁寺、青果巷、淹城、天目湖与南山竹海。  
引用白居易：“江南好，风景旧曾谙。”

苏州：太湖、拙政园、平江路、虎丘、金鸡湖与阳澄湖。  
引用杜荀鹤：“君到姑苏见，人家尽枕河。”

南通：长江、黄海、狼山、濠河、通州湾与圆陀角。  
引用王湾：“潮平两岸阔，风正一帆悬。”

连云港：黄海、花果山、连岛、连云港港、海州古城与孔望山。  
引用吴承恩：“心生种种魔生，心灭种种魔灭。”

淮安：洪泽湖、京杭大运河、河下古镇、清江浦、周恩来故里与明祖陵。  
引用苏轼：“大江东去，浪淘尽，千古风流人物。”

盐城：黄海、丹顶鹤湿地、中华麋鹿园、大纵湖、盐城港与串场河。  
引用王维：“行到水穷处，坐看云起时。”

扬州：瘦西湖、大明寺、个园、何园、东关街与京杭大运河。  
引用杜牧：“二十四桥明月夜，玉人何处教吹箫。”

镇江：长江、金山寺、北固山、焦山、西津渡与京杭大运河。  
引用辛弃疾：“何处望神州？满眼风光北固楼。”

泰州：凤城河、溱湖湿地、兴化垛田、梅兰芳纪念馆、光孝寺与长江。  
引用郑板桥：“咬定青山不放松，立根原在破岩中。”

宿迁：骆马湖、京杭大运河、项王故里、三台山、洋河酒乡与黄河故道。  
引用项羽：“力拔山兮气盖世。”

## 发布文案

把江苏画成一张立体手绘地图，才发现它的地理性格特别丰富。

长江从西向东穿过南部，京杭大运河从北向南串起城市，太湖在江南铺开水乡园林，洪泽湖和骆马湖把北部湖泊湿地托起来，黄海岸边又有盐城的滩涂、连云港的山海港湾和南通的江海交汇。

江苏的美，不只是“江南很温柔”，而是江、河、湖、海同时塑造了这片土地。

一半是水乡园林。  
一半是江海气象。

如果每个省都做成这样的手绘地理图，你最想先看哪个省？
