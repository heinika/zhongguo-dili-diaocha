## 空间硬约束与逐图核验

### 00 新疆总览

1. 北向向上，不旋转、不镜像，不画海岸。
2. 阿尔泰山在最北、准噶尔盆地在北疆。
3. 天山东西横贯中部，明确分隔南北疆。
4. 塔里木盆地和塔克拉玛干在南疆，昆仑山沿南缘，帕米尔在最西。
5. 乌鲁木齐/昌吉位于天山北麓；吐鲁番在天山东部南侧；哈密在最东。
6. 塔里木河沿盆地北缘总体自西向东；喀纳斯湖、赛里木湖、博斯腾湖方位区分。
7. 喀什/克州在西南、和田在南缘、阿克苏在西北缘、巴州在东南。
8. 核验：三山两盆、主要河湖、14 地州节点均入轮廓；无海岸、无镜像、无水系逆向。

### 01 喀什

1. 帕米尔高原在西部和西南部，塔克拉玛干边缘在东。
2. 喀什城与主绿洲位于东北侧低地。
3. 塔什库尔干及石头城在最西南高谷。
4. G314 由喀什向西南，经卡拉库里湖、慕士塔格峰走廊至塔县。
5. 叶尔羌河由南部山地流向绿洲；达瓦昆在东部绿洲—沙漠过渡带。
6. 核验：城市、湖、峰、古城与公路顺序正确，未把绿洲放进高原腹地。

### 02 乌鲁木齐

1. 市域南高北低，主城区在天山北麓。
2. 乌鲁木齐河由南部山区向北穿城。
3. 红山与大巴扎绑定中心城区。
4. 南山和天山大峡谷在南部。
5. 达坂城、柴窝堡湖在东南通道。
6. 核验：博格达峰在城市东侧山地，铁路公路顺谷地通过，未跨雪峰。

### 03 伊犁

1. 采用伊犁州直范围，不吞并塔城、阿勒泰。
2. 伊犁河由东向西穿河谷并出境。
3. 伊宁在西部主河谷，霍城/果子沟更靠西北。
4. 昭苏—夏塔在西南高盆地。
5. 特克斯—喀拉峻在南部；巩留—新源—那拉提向东展开。
6. 核验：河谷、山系与城镇顺序正确；未把赛里木湖误划入州直。

### 04 阿克苏

1. 天山与托木尔峰在北/西北，塔克拉玛干在南。
2. 阿克苏—温宿绿洲在西部山前扇。
3. 阿克苏河由北部山地南下汇入塔里木水系。
4. 拜城在北部盆地，库车在东部山前。
5. 克孜尔石窟位于库车以西北的渭干河谷。
6. 核验：塔里木河沿沙漠北缘向东，胡杨贴河分布，城镇未落入沙漠腹地。

### 05 和田

1. 塔克拉玛干在北，昆仑山在南。
2. 玉龙喀什河、喀拉喀什河由昆仑山北下。
3. 和田位于两河绿洲。
4. 绿洲节点严格按西向东排列：皮山—墨玉—和田—洛浦—策勒—于田—民丰。
5. 尼雅遗址绑定最东部民丰。
6. 核验：首稿因墨玉错置未采用；重制稿已纠正完整西东次序。

### 06 巴州

1. 巴音布鲁克在西北高山盆地，阿尔金山在东南。
2. 博斯腾湖在天山东南，库尔勒位于其西南侧。
3. 孔雀河由博斯腾湖西出、流经库尔勒。
4. 塔里木河沿塔克拉玛干北缘西东流，轮台胡杨贴河。
5. 且末在南缘西侧，若羌在更东，罗布泊/楼兰在东部干旱盆地。
6. 核验：湖、河、沙漠、南部绿洲、公路走廊均无方向颠倒。

### 07 昌吉

1. 天山在南，古尔班通古特沙漠在北。
2. 西部绿洲顺序：玛纳斯—呼图壁—昌吉。
3. 阜康在乌鲁木齐东侧山前，天池与博格达峰在阜康南部。
4. 东部依次为吉木萨尔—奇台—木垒。
5. 北庭故城绑定吉木萨尔，江布拉克绑定奇台，胡杨绑定木垒。
6. 核验：城镇均位于山前绿洲带，交通线未跨越雪山。

### 08 塔城

1. 保留西北塔城盆地与东南乌苏—沙湾走廊。
2. 塔尔巴哈台山在北，塔城在西北盆地，巴克图口岸在塔城以西。
3. 额敏河总体向西流，额敏在塔城东南。
4. 裕民在南/西南，托里更东南，和布克赛尔在东部萨吾尔山一侧。
5. 克拉玛依作为独立地级市形成中部缺口，不被塔城吞并。
6. 核验：乌苏在沙湾以西、两者均位于东南天山北麓走廊。

### 09 吐鲁番

1. 博格达山在北，盆地北高南低。
2. 火焰山东西横贯盆地北部/中部。
3. 高昌居西中部，交河在其西侧，葡萄沟切入火焰山谷。
4. 托克逊在西，鄯善在东，库木塔格紧邻鄯善东侧。
5. 艾丁湖位于南部低地，为内陆盐湖。
6. 核验：山、盆、湖、绿洲的环带结构与官方地貌说明一致。

### 10 哈密

1. 东天山东西横贯中北部。
2. 巴里坤湖/巴里坤在山北，伊吾更靠东北。
3. 哈密城在东天山以南的哈密盆地。
4. 大海道与五堡魔鬼城在西南戈壁。
5. 铁路公路由西入哈密再向东，不翻越主峰。
6. 核验：首稿指北针含拉丁字母 N 未采用；重制稿改为汉字“北”。

### 11 阿勒泰

1. 阿尔泰山在北和东北。
2. 喀纳斯湖、禾木在西北山林，布尔津在其南。
3. 阿勒泰市在中北部山前，北屯在其南。
4. 额尔齐斯河由富蕴/可可托海一侧向西北流。
5. 乌伦古湖与福海位于南部盆地，和喀纳斯湖明确区分。
6. 核验：高山、森林、河谷、南部湖盆空间层级清楚，河流未逆向。

### 12 克州

1. 帕米尔高原在西/南，阿图什位于东部山前出口。
2. 乌恰在阿图什以西，伊尔克什坦口岸在最西。
3. 克孜勒苏河由西部山地向东流。
4. 阿合奇在北部山谷，与南部阿克陶分开。
5. 白沙湖在北、喀拉库里湖在南，公格尔峰与慕士塔格峰环列南部走廊。
6. 核验：首稿指北针含 N 未采用；重制稿已改为“北”且山河节点不变。

### 13 克拉玛依

1. 明确画成不连续的北部主体与南部独山子两块。
2. 北部主体由北向南为乌尔禾/魔鬼城—白碱滩—克拉玛依城区。
3. 黑油山、一号井绑定主城区。
4. 克拉玛依河穿过主城区绿带。
5. 独山子单独位于南部天山北麓，峡谷与独库公路绑定独山子。
6. 核验：两块之间保留宣纸空白，不以假走廊连接。

### 14 博州

1. 阿拉套山及边境高地在西/西北，艾比湖盆地在东。
2. 温泉在西部山谷，博乐在其东。
3. 博尔塔拉河由西向东穿绿洲。
4. 赛里木湖在西南山地，未误划入伊犁州直。
5. 精河在博乐以东，艾比湖在东部，阿拉山口在东北风口。
6. 核验：铁路由精河通向阿拉山口，甘家湖梭梭林位于东部干旱区。
