# 全国省份手绘地图

本目录用于按省份归档手绘地理海报图片与发布文案。

## 目录结构

```text
全国省份手绘地图/
  项目总清单.md
  省级生成计划.md
  福建省/
    images/
      01-福建省总图.png
      02-福州市.png
      ...
    小红书配文.md
```

## 命名规则

- 每个省级行政区单独一个文件夹，例如：`福建省`、`广东省`、`浙江省`。
- 图片统一放在该省的 `images` 文件夹内。
- 图片编号建议使用：
  - `01-省份总图.png`
  - `02-城市名.png`
  - `03-城市名.png`
- 每个省份保留一份 `小红书配文.md`，用于图文发布。

## 文案规则

- 标题突出省份核心气质。
- 正文说明山川、河流、海岸、城市和人文特色。
- 城市条目包含本地地标与诗词引用。
- 诗词优先使用本地诗人；其次使用确实描写本地山水、古迹或文化意象的古代诗文。
- 结尾包含互动提问和话题标签。

## 四阶段执行

1. 省级总图：先为 34 个省级行政区建立目录并生成省级总图。
2. 地市分图：逐省生成地级行政区图片，直辖市、港澳台按独立口径处理。
3. 文字叠加：以手绘底图为基础，统一叠加准确标题、标注、诗词和小红书配文。
4. 交付导出：每省输出 `images`、`final`、`小红书配文.md` 和清单文件。
